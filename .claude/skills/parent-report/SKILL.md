# مهارة: تقرير ولي الأمر (parent-report)

بطاقة متابعة صفحة واحدة لولية/ولي الأمر — للطباعة أو الحفظ PDF (§5).

## التشغيل
```bash
node generate.mjs --student "<اسم الطالبة>" [--term 1|2]
```
- `--student` اسم الطالبة (تطابق جزئي).
- `--term` الفصل الدراسي (الافتراضي ١).

### ما تقوله المعلّمة → الأمر
- «اعملي تقرير لولي أمر سارة» → `--student "سارة"`
- «بطاقة متابعة نورة للفصل الثاني» → `--student "نورة" --term 2`

## المخرج (في `المخرجات/`)
بطاقة HTML فيها: بيانات الطالبة · جدول الدرجات بالمكوّنات · النسبة والتقدير ·
الحضور · النقاط والمستوى · الأوسمة · توصيات مخصّصة · مكان توقيع ولي الأمر.

## القواعد
- الصيغة مؤنثة (حصلت/غابت/الطالبة) وموجّهة لولية/ولي الأمر.
- التوصيات مشتقّة من أرقامها لا عامة (§2-ز).
- الأرقام والتقدير من سياسة التقييم في البيانات (§4) · لا اتصال خارجي (§2-هـ).
