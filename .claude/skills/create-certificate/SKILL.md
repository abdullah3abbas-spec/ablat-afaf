# مهارة: شهادات تقدير (create-certificate)

تُصدر شهادات جاهزة للطباعة (صفحة لكل شهادة، §5).

## التشغيل
```bash
# لطالبة واحدة:
node generate.mjs --template excellence --student "نورة المهندي"
# لأوائل فصل (بالدرجات أو بالنقاط):
node generate.mjs --template star_of_month --class "خامس ١" --top 5 --by points
# للفصل كله (شكر/مشاركة):
node generate.mjs --template excellence --class "خامس ١" --all
```
- `--template` القالب: `excellence` (تفوّق) · `star_of_month` (نجمة الشهر) · `most_improved` (الأكثر تحسّناً) · `best_experiment` (أفضل تجربة) · `guardian_thanks` (شكر لولية الأمر). أو اسمه العربي.
- `--student` اسم طالبة (شهادة واحدة).
- `--class` + `--top N` أوائل الفصل · `--by grades|points` معيار الترتيب (الافتراضي grades).
- `--class` + `--all` كل طالبات الفصل.
- `--reason "نص"` سبب مخصّص (وإلا نص القالب الافتراضي).
- `--qr` إضافة رمز QR للتحقق المحلي.

### ما تقوله المعلّمة → الأمر
- «اطبعي شهادات لأوائل الشهر» → `--template star_of_month --class "خامس ١" --top 5 --by points`
- «شهادة تفوّق لنورة» → `--template excellence --student "نورة"`

## المخرج
ملف HTML واحد فيه كل الشهادات (صفحة لكل شهادة) في `المخرجات/`. افتحيه واطبعي.

## القواعد
الصيغة مؤنثة (تشهد … بأن الطالبة … حصلت) · الأرقام شرقية في الشهادات (§5) ·
لا اتصال خارجي، الأسماء محلية (§2-هـ).
