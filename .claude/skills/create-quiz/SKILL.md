# مهارة: تقييم صفي قصير (create-quiz)

كويز سريع من بنك الأسئلة — ورقة صفحة واحدة + نموذج إجابة. للطباعة الفورية (§5).

## التشغيل
```bash
node generate.mjs --lesson "<اسم الدرس>" [--count 5] [--minutes 5]
# أو على وحدة كاملة:
node generate.mjs --units "<اسم الوحدة>" [--count 8]
```
- `--lesson` اسم الدرس (تطابق جزئي). أو `--units` اسم/أرقام الوحدات.
- `--count` عدد الأسئلة (الافتراضي ٥).
- `--minutes` الزمن بالدقائق (الافتراضي ٥).

### ما تقوله المعلّمة → الأمر
- «كويز ٥ دقائق على دورة الماء» → `--lesson "دورة الماء" --count 5 --minutes 5`
- «تقييم قصير على وحدة المادة» → `--units "المادة" --count 8`

## المخرجات (في `المخرجات/`)
- **ورقة الكويز** — العنوان والاسم والأسئلة، صفحة واحدة.
- **نموذج الإجابة** في نهاية الملف (صفحة منفصلة تقتطعها المعلّمة).

## القواعد
الأسئلة من البنك فقط · العربية فقط · الصيغة مؤنثة · لا اتصال خارجي (§2-هـ، §5).
