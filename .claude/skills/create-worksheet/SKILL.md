# مهارة: ورقة عمل (create-worksheet)

ورقة عمل بترويسة المدرسة + الأهداف + الأنشطة، ونسخة إجابات. للطباعة (§5).

## التشغيل
```bash
node generate.mjs --lesson "<اسم الدرس>" [--count 6] [--title "عنوان مخصّص"]
# أو على وحدة:
node generate.mjs --units "<اسم الوحدة>" [--count 8]
```
- `--lesson` اسم الدرس (تطابق جزئي) · أو `--units` وحدة/وحدات.
- `--count` عدد الأنشطة (الافتراضي ٦).
- `--title` عنوان مخصّص (اختياري).

### ما تقوله المعلّمة → الأمر
- «ورقة عمل على الجهاز الهضمي» → `--lesson "الجهاز الهضمي"`
- «ورقة نشاط وحدة المادة، ٨ أسئلة» → `--units "المادة" --count 8`

## المخرجات (في `المخرجات/`)
- **ورقة العمل** — ترويسة، اسم/تاريخ، الأهداف، الأنشطة بمساحات إجابة.
- **نسخة الإجابات** في نهاية الملف (صفحة منفصلة للمعلّمة).

## القواعد
الأسئلة من البنك فقط (§2-و) · العربية · الصيغة مؤنثة · لا اتصال خارجي (§2-هـ).
