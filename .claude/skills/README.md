# مهارات منصّة أبلة عفاف

سبع مهارات تحوّل جملة عربية واحدة إلى مخرج جاهز (§10 من CLAUDE.md).

| المجلد | تنتج | مثال |
|--------|------|------|
| `create-exam` | اختبار رسمي + نموذج إجابة + جدول مواصفات | «اعملي اختبار نهاية الفصل للوحدة ٢ و ٣» |
| `create-quiz` | تقييم صفي قصير + نموذج إجابة | «كويز ٥ دقائق على الجهاز الهضمي» |
| `create-worksheet` | ورقة عمل بالترويسة + نسخة إجابات | «ورقة عمل على أجهزة جسم الإنسان» |
| `lesson-plan` | خطة تحضير Word بنموذج المدرسة | «حضّريلي درس المغناطيس» |
| `create-certificate` | شهادات تقدير (٥ قوالب) + QR | «اطبعي شهادات لأوائل الشهر» |
| `parent-report` | بطاقة متابعة لولي الأمر | «تقرير لولي أمر سارة» |
| `official-export` | كشف Excel بترتيب أعمدة النظام | «كشف الدرجات لخامس ١» |

## كيف تعمل؟

1. **جسر البيانات:** المهارات تعمل في Node (خارج المتصفح)، فلا تصل إلى قاعدة البيانات
   مباشرة. المعلّمة تصدّر بياناتها مرة كملف JSON من: **الإعدادات ← تصدير بيانات للمهارات**،
   وتضعه في مجلد `data/`. المهارة تبحث تلقائياً عن أحدث ملف في `data/` أو `~/Downloads`.
2. **مكتبة مشتركة** (`_shared/`): تحميل البيانات، حساب الدرجات (منقول حرفياً من `src/lib`
   ليطابق التطبيق)، الأرقام والتواريخ العربية، تضمين الخطوط للطباعة، ومنطق بناء الاختبار.
3. **المخرجات** في مجلد `المخرجات/` بأسماء عربية مؤرّخة.

## القواعد الحاكمة

- **محلي بالكامل:** لا اتصال بأي خدمة خارجية. أسماء الطالبات لا تغادر الجهاز (§2-هـ).
- **الصيغة مؤنثة** في كل مخرج (§1).
- **العربية الصحيحة (§5):** PDF عبر طباعة المتصفح (HTML بخطوط مضمّنة) لا مكتبات JS؛
  Word وExcel باتجاه `rightToLeft`.
- **الأرقام والسياسة بيانات لا كود:** تُقرأ من ملف البيانات (§4).

## التشغيل اليدوي (للاختبار)

```bash
cd .claude/skills/create-exam
node generate.mjs --type final --units all --variants A,B
```

لكل مهارة `SKILL.md` يشرح وسائطها. لتوليد عيّنة بيانات للتجربة:
`npx vite-node scripts/genSampleData.mts` من جذر المشروع.
