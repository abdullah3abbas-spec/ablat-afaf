# موصِل أم عازِل؟

لعبة تصنيف لايف لدرس مشاهدة علوم الصف الخامس (المنهج القطري، الدرس 3.3: المُوصِلات والعوازِل الكهربائية).

- `#/teacher`: شاشة المعلمة على السبورة (التهيئة بالفيديو، اللعبة لايف، النتائج، أسئلة التقييم).
  - فيديوهات التهيئة ثلاثة (زر «النسخة»): التفاعلية `hook.mp4` · حوار الدائرتين `dialogue.mp4` · الأولى `hook_v1.mp4`. التفاعلية والحوار يتوقّفان وحدهما عند أسئلة التفاعل.
- `#/g/<رقم>?r=<رمز الصف>`: شاشة آيباد المجموعة، وتُفتح من رمز QR على السبورة.

موقع ثابت بلا خطوة بناء. الاتصال اللحظي عبر Supabase Realtime (بث فقط، بدون تخزين بيانات).
