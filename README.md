# موصِل أم عازِل؟

أدوات حصة علوم الصف الخامس (المنهج القطري، الدرس 3.3: المُوصِلات والعوازِل الكهربائية).

رابط الموقع: https://abdullah3abbas-spec.github.io/ablat-afaf/

## للآيباد (رابط واحد لكل المجموعات، وكل مجموعة تختار رقمها من 1 إلى 5)
- `#/lab`: المختبر الافتراضي (النشاط 2): خمس موادّ في دائرة، وجدول الكتاب ص 176 على الجهاز مع مثالَي الملعقتين.
- `#/sort`: لعبة «أضيئي المدينة» (غلق الهدف الثاني): ثماني كلمات لموادّ جديدة تُصنَّف في جدولَي الموادّ المُوصِلة والعازِلة.

## لشاشة المعلمة (السبورة)
- `#/lab/board`: متابعة جداول المجموعات لحظة بلحظة، وزر «إظهار التصحيح»، و«جولة جديدة».
- `#/sort/board`: المدينة: كل إجابة صحيحة تُنير نافذة في مبنى المجموعة، وزر «ابدئي السباق» و«النتائج».
- أضيفي `?demo=1` بعد أيٍّ منهما للتجربة بمجموعات وهمية، مثل `#/sort/board?demo=1`.
- `#/teacher`: أدوات الحصة السابقة (فيديوهات التهيئة واللعبة بالصور والتقييم).

موقع ثابت بلا خطوة بناء. الاتصال اللحظي عبر Supabase Realtime (بث فقط، بدون تخزين بيانات).
