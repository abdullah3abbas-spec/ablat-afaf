# منصّة أبلة عفاف 🌿

منصّة ويب محلية (Local-first PWA) لمعلّمات المدارس الابتدائية — بُنيت أصلاً لمعلّمة علوم للمستوى الخامس بالمنهج القطري، و**قابلة للتخصيص لأي معلّمة** من شاشة الإعدادات: اسم المنصّة، اسم المعلّمة، المدرسة، المادة، وصور الترويسة والشعارات — من غير لمس أي كود.

**القاعدة الذهبية:** المعلّمة لا تُدخل بيانات — هي تفتح، وتختار، وتصوّر، وتطبع.

## المميزات

- **الفصول والطالبات** — ملف كامل لكل طالبة (بيانات، درجات، حضور، نقاط، ملاحظات)، لصق قائمة أسماء أو استيراد Excel.
- **الدرجات** — رصد مرن حسب سياسة التقييم القطرية (الأوزان قابلة للتعديل سنوياً من الإعدادات، ليست في الكود).
- **قارئ الدرجات بالتصوير** — تصوير ورقة الرصد بالموبايل بدل الإدخال اليدوي، مع شاشة مراجعة إلزامية.
- **المكتبة الجاهزة** — لكل درس: عرض تقديمي، ورقة عمل بنظام أوراق المدرسة الحقيقية (بلوحات نشاط مصوّرة)، لعبة حصة، تجربة عملية، كرت خروج، خطة درس Word بالنموذج الوزاري، وورقة مشاركة. زر واحد يطبع حزمة الأسبوع كاملة.
- **الاختبارات** — كويزات ومنتصف ونهاية الفصل بنظام الوزارة + نموذج إجابة + جدول مواصفات.
- **الشهادات** — ٨ قوالب بلوحات مرسومة بالكامل ومحرّر داخل المنصّة، وتوليد جماعي للفصل.
- **وضع الفصل** — شرائح وألعاب على البروجكتور مع اختيار عادل ومؤقّت وفرق.
- **التقارير** — بطاقات أولياء الأمور، تقرير الإدارة، كشف Excel بترتيب النظام الرسمي، وتحليلات بإنذار مبكر.
- **اسألي المنهج** — إجابة من الكتاب المرفوع فقط مع الاستشهاد بالصفحة.

## الخصوصية — غير قابلة للتفاوض

كل البيانات محلية على الجهاز (IndexedDB). **أي شيء فيه اسم طالبة لا يخرج من الجهاز أبداً.** الذكاء الاصطناعي يستقبل محتوى المنهج فقط عبر بوابة وسيطة واحدة (`gateway/`) بمفاتيح على الخادم وحارس ميزانية، مع شاشة «ما سيُرسل» وسجل إرسال وزر قطع الاتصال — والمنصّة تعمل بكامل وظائفها الأساسية بلا إنترنت.

## التقنيات

React 18 + TypeScript + Vite · Tailwind CSS (RTL) · Dexie.js/IndexedDB · Zustand · PWA · طباعة PDF عبر المتصفح (تشكيل عربي مثالي) · docx / exceljs / pptxgenjs · Cloudflare Pages + Worker واحد للبوابة.

## التشغيل

```bash
npm install
npm run dev        # التطوير
npm run build      # البناء
npx vitest run     # الاختبارات (237)
```

## التخصيص لمعلّمة جديدة

من داخل المنصّة: **الإعدادات ← هوية المنصّة والمدرسة** — غيّري الأسماء والمادة وارفعي ترويسة وشعارات مدرستك، فتتبعها كل الشاشات والمطبوعات فوراً. الافتراضيات تعود بمسح أي حقل.

> دليل الاستخدام الكامل بالعربية في `دليل-الاستخدام.md`، ودستور المشروع للمطوّرين في `CLAUDE.md`.
