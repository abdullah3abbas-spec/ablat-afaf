## ١. الخلاصة التنفيذية

المنصّة الحالية **ليست نماذج أولية متفرقة** كما يفترض الماستر برومبت — هي منصّة مكتملة مبنية على ٢١ كومِت، فيها ٢٧ شاشة و**١٣٣ اختباراً آلياً ناجحاً** وبناء سليم، ومنشورة وتعمل بلا إنترنت (PWA). التحويل الصحيح إذن **إعادة هيكلة وبناء فوقها**، لا هدم — وهو ما يأمر به الماستر برومبت نفسه («لا تهدم ما يعمل ولا تغيّر التقنية بلا سبب واضح»).

الفجوات الحقيقية أمام رؤية زكريت خمس: (أ) الذكاء الاصطناعي المتصل غير موجود إطلاقاً (التطبيق محلي ١٠٠٪ بقرار دستوري)، (ب) العروض التقديمية الحالية نصية القالب لا «درساً بصرياً»، (ج) لا يوجد Classroom Mode للبروجكتور، (د) الألعاب الحالية ٤ أدوات بسيطة لا Game Hub بقوالب، (هـ) التجارب إرشادات ورقية لا محاكاة تفاعلية.

## ٣. نقطة الاسترجاع (خطة Rollback)

- وسم git: **`نسخة-١-قبل-تحويل-زكريت`** + فرع أمان: **`أمان/ما-قبل-تحويل-زكريت`**
- لا يوجد remote — المستودع محلي؛ النسخ الخارجية = تاريخ نشر Cloudflare Pages (كل نشرة قابلة للاسترجاع من اللوحة) + زر النسخة الاحتياطية داخل التطبيق.
- الاسترجاع: `git checkout نسخة-١-قبل-تحويل-زكريت` ثم بناء ونشر.

## ٥. خريطة الفجوات مقابل أقسام الماستر برومبت

| قسم الماستر برومبت | الوضع اليوم | الفجوة |
|--------------------|-------------|--------|
| مركز اليوم | موجود مزدحم | تبسيط + «ابدئي حصة اليوم» كمسار واحد |
| مكتبتي والمنهج | مركز مصادر أساسي | ingestion كامل: OCR، تحليل، حالات، تكرارات، نسخ |
| استوديو (مصادر + اسألي المنهج + توليد) | لا يوجد Chat ولا RAG؛ يوجد صندوق أوامر محلي وتوليد قوالب | **أكبر فجوة** — تحتاج ذكاءً اصطناعياً متصلاً |
| العروض البصرية (60٪ شرائح بصرية، Speaker Notes، تصدير PPTX) | عروض قوالب نصية | إعادة بناء المولّد |
| فيديو الشرح | غير موجود | جديد كلياً (مرحلة ٣، خلف تقدير تكلفة) |
| Classroom Mode | غير موجود (أقربه لوحة الصدارة والأدوات) | جديد — واجهة بروجكتور + شاشة تحكم |
| Game Hub (١١ قالباً) | ٤ أدوات | بناء القوالب فوق بنك الأسئلة |
| Interactive Lab | إرشادات تجارب نصية | محاكاة HTML5/SVG تفاعلية |
| AI Gateway + Router + Budget Guardian | غير موجود (محظور دستورياً حتى الآن) | يحتاج **قرارك** — انظر §٦ |
| Auth وأدوار | قفل PIN محلي فقط | حسب القرار المعماري |
| RAG وCitations | غير موجود | يُبنى مع المكتبة |

## ٦. التعارضات الجوهرية — تحتاج قرار المالك قبل المرحلة ٢

1. **دستور المشروع (`CLAUDE.md`) يمنع منعاً باتاً**: أي خدمة سحابية، أي API خارجي، أي حسابات — بينما الماستر برومبت يطلب AI Gateway (Gemini + OpenAI) وWorkers وD1/R2/Vectorize وAuth.
   **التوفيق المقترَح (يحفظ روح الدستور):** يبقى التطبيق محلياً أولاً — *كل* بيانات الطالبات (أسماء، درجات، صور، ملاحظات) تبقى في جهاز المعلّمة ولا تُرسل أبداً (قاعدة «أي شيء فيه اسم بنت لا يخرج من الجهاز» تبقى غير قابلة للتفاوض، و`aiGuard.ts` يفرضها كوداً). يُضاف **Worker وسيط خفيف** واحد: يحمل مفاتيح API بأمان (لا مفاتيح في الواجهة)، يمرّر محتوى المنهج فقط، وفيه عدّاد الميزانية والتنبيهات والكاش. المنهج (كتب، ملازم، عروض) يُخزَّن في R2/Vectorize للفهرسة — وهو محتوى غير حسّاس أصلاً. بلا إنترنت: كل ما هو معتمد يعمل من الكاش، والتوليد الجديد فقط يتوقف.
2. **المفاتيح والميزانية**: 50$ لكل مزوّد (Gemini + OpenAI). إنشاء الحسابات والمفاتيح **بيدك أنت** (لا أنشئ حسابات نيابة عنك)، وأنا أجهّز أوامر تخزينها كأسرار في Cloudflare وأبني Budget Guardian.
3. **تعديل الدستور**: بعد موافقتك أعدّل `CLAUDE.md` (استثناء البوابة الوسيطة من حظر السحابة، وإضافة هوية زكريت وأقسام الهيكل الجديد) حتى لا تعمل الجلسات القادمة بقواعد متناقضة.

## ٧. خطة المراحل الموفَّقة على الكود القائم

- **المرحلة ١ — الأساس والتجربة (لا تحتاج مفاتيح):** Design System موحّد (Tokens محايدة + Theme لهوية زكريت لاحقاً) · إعادة بناء `/` كمركز اليوم · إعادة هيكلة التنقّل والأقسام · ترحيل الأدوات لمواضعها الجديدة · WCAG 2.2 AA.
- **المرحلة ٢ — المنهج والذكاء الاصطناعي (تحتاج القرار + المفاتيح):** Worker الوسيط + Router + Budget Guardian · ingestion/OCR/فهرسة/RAG بـCitations · «اسألي المنهج» · بطاقات الاستوديو.
- **المرحلة ٣ — المحتوى المرئي:** مولّد العروض البصرية (Storyline، ≥60٪ شرائح بصرية، Speaker Notes، تحرير، PPTX/PDF/عرض داخل الموقع) · Infographic · خرائط ذهنية · الصوت/الفيديو خلف تقدير تكلفة.
- **المرحلة ٤ — الفصل والألعاب والتجارب (معظمها لا يحتاج مفاتيح):** Classroom Mode (بروجكتور + شاشة معلّمة) · Game Hub بالقوالب الأحد عشر فوق بنك الأسئلة · Interactive Lab (محاكاة SVG/Canvas) · دخول الطالبات بكود حصة بلا حسابات.
- **المرحلة ٥ — التحقق والتسليم:** مصفوفة الاختبارات كاملة، Usability لمستخدمة ٦٠ سنة، أمان وأداء، توثيق مبسّط + تقني.

**ملاحظتان من الدستور القديم تبقيان على الرادار:** «الملاحظات الصوتية بعد الحصة» (§2-ز) تُبنى داخل مركز اليوم الجديد، و«وضع الابن» (الوحدة ١٥) يتحقق طبيعياً بدور «مشرفة/إدارة» في هيكل زكريت.
