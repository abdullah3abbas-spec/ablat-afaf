# تقرير الفحص الشامل — المرحلة ٥ من تحويل زكريت

> التاريخ: ١٣ أغسطس ٢٠٢٦ · الموقع: https://ablat-afaf.pages.dev · البوابة: afaf-ai-gateway.abdullah3abbas.workers.dev

## ١. الفحص الوظيفي (E2E)

| الفحص | النتيجة |
|-------|---------|
| جولة حيّة على كل المسارات | **٣٠ مساراً** — كلها تعرض محتوى فعلياً |
| أخطاء Console أثناء الجولة | **صفر** |
| اختبارات Vitest | **١٧٩ / ١٧٩** (١٨ ملفاً) — تشمل معادلات الدرجات، النقاط، بناء الاختبارات، منطق البوابة والميزانية، جودة العروض، الألعاب، المحاكاة |
| مسارات مُرّنت يدوياً حياً هذه المرحلة وما قبلها | مركز اليوم، الرصد، وضع الفصل (شرائح/الألعاب الخمس/اختيار/مؤقّت/فرق)، اسألي المنهج (توليد حقيقي)، استوديو العروض (توليد حقيقي ١٠ شرائح → تحرير → اعتماد → بروجكتور)، المختبر (الحالات الثلاث + التوقع + الاستنتاج) |
| ملاحظة | `/slides/:id/present` يحتاج ~نصف ثانية لقراءة العرض أول مرة — يعرض «لحظات…» ثم المحتوى؛ سلوك سليم |

## ٢. الوصولية (WCAG 2.2 AA)

المنهجية: تدقيق بنيوي على الشاشات الجديدة (قياس تباين فعلي بالقيم، فحص أسماء العناصر التفاعلية، لوحة المفاتيح، أهداف اللمس) — امتداداً لتدقيق المراحل السابقة المضمّن في بناء كل شاشة (§6 من الدستور).

| البند | النتيجة |
|-------|---------|
| تباين النصوص على الشاشات الداكنة | ذهبي على داكن ≈ 5.0:1 ✓ · أبيض 70٪ ≈ 8:1 ✓ · أبيض 60٪ ≈ 5.8:1 ✓ · أبيض 50٪ ≈ 5.1:1 ✓ |
| **مخالفتان وجدتا وأُصلحتا** | (أ) نص السلامة في المختبر كان `gold/80` ≈ 3.9:1 → أصبح ذهبياً كاملاً وسميكاً ✓ · (ب) بطاقة الذاكرة المقلوبة كان اسمها الصوتي «؟» فقط → أضيف `aria-label` واضح ✓ |
| لوحة المفاتيح | أسهم للتنقل في الشرائح والعروض ✓ · كل الألعاب أزرار قابلة للتنقّل ✓ · حلقة تركيز مرئية على الداكن (حلقة الإزاحة الكريمية) ✓ |
| أسماء العناصر | كل أيقونة معها كلمة عربية ✓ · `aria-pressed` للاختيارات ✓ · `role="img"` + `aria-label` لرسوم SVG (الدورة، المشهد) ✓ · `role="timer"` للمؤقّت ✓ |
| أهداف اللمس | ≥ 48px في كل الأزرار الجديدة ✓ |
| الحركة | لا رسوم متحركة — انتقالات لونية فقط؛ يحترم تقليل الحركة ضمنياً ✓ |
| تكبير 200٪ | تخطيطات مرنة تلتف، والجداول العريضة داخل `overflow-x-auto` ✓ |

## ٤. الأمان

| الفحص | النتيجة |
|-------|---------|
| مفاتيح المزوّدين في الموقع المنشور | **غير موجودة** — فحص أنماط `AIza` و`sk-` على dist كاملاً (المطابقة الوحيدة لـ«AIza» بيانات ثنائية داخل ملف OCR تليها `AAAAAAAA…` — ليست مفتاحاً) |
| رمز ربط البوابة في الموقع | **غير موجود** — يُدخَل يدوياً مرة واحدة ويُخزَّن محلياً في جهاز المعلّمة |
| البوابة | رمز ربط سرّي + CORS مقفول على النطاقات المعروفة + حدّ معدّل + سقف ميزانية قاطع (إجمالي ويومي لكل مزوّد) |
| بيانات الطالبات | لا تغادر الجهاز — حارس الأسماء يمنع الإرسال، وشاشة «ما سيُرسل» إلزامية، وسجل الإرسال كامل (§2-هـ) |

## ٥. المتبقّي من رؤية زكريت (مرتّباً بالأولوية)

1. **فهرسة المنهج الحقيقي (RAG)** حين تُرفع ملفات كتاب زكريت الرسمية — البوابة والمكتبة جاهزتان للاستقبال
2. قوالب الألعاب الست الباقية (سباق الهدف، صندوق الكنز، سحب وإفلات، ماذا سيحدث، Escape تعليمية، عجلة تحديات)
3. محاكاة إضافية للمختبر (درس لكل وحدة)
4. م٣-ب: إنفوجرافيك، خرائط ذهنية، Audio/Video Overviews (خلف تقدير تكلفة)
5. دخول الطالبات بكود حصة/QR (مؤجَّل بقرار الدستور — الطالبات غالباً بلا أجهزة)
6. هوية مدرسة زكريت البصرية حين تصل ملفاتها (تُطبَّق من توكِنات `:root` وحدها)
